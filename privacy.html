隐私政策

本页说明 rclone OAuth 应用（以下简称“本应用”）如何处理您的数据。

1. 处理的数据

本应用通过 Google Drive API 访问您 Google 账号中的文件及文件元数据，仅用于文件备份与同步。

2. 数据存储位置

数据仅保存在您本人的设备或您自行管理的服务器上。本应用没有后端服务器，不会将任何数据上传或转发给第三方。

3. OAuth 令牌

授权令牌保存在您本机/本服务器的 rclone 配置文件中，仅用于向 Google 发起 API 请求，不会对外传输。

4. 数据共享

本应用不向任何第三方出售、出租或共享您的数据，也不将数据用于广告或画像。

5. 数据保留与删除

您可随时在 Google 账号权限页 撤销授权；撤销后本应用将无法再访问您的数据。删除本地 rclone 配置文件即可清除已保存的令牌。

6. 联系方式

如有疑问，请在 项目 Issues 页面留言。
